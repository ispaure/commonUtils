# commonUtils

Reusable filesystem, runtime, format and UI mechanisms for Python applications.

commonUtils is a library embedded by applications, not a standalone app. The
application chooses dependencies, file locations and workflows.

Start with the [documentation wiki](docs/docs.md) and the runnable
[first-use example](docs/development/getting-started.md). Use the
[API reference](docs/development/reference/reference.md) when implementing an
integration, or [component user guides](docs/user/user.md) for controls inside a
host application.
