# Shared component user guides

These guides describe controls embedded in another application. Open the host
application first; commonUtils has no separate launcher, accounts screen or
installation wizard. The host may hide actions or restrict folders. Use its
help for connection setup, document storage and feature enablement.

## Find the right guide

| --- | --- |

| Read or edit a wiki page | [Markdown](markdown/markdown.md) |
